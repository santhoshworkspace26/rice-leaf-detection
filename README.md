# Rice Leaf Disease Detection 🌾

A deep learning based web application for detecting rice leaf diseases using Vision Transformer (ViT).

## Features
- Upload rice leaf image
- Detect disease
- Flask web app
- Deep learning model using PyTorch

## Technologies Used
- Python
- Flask
- PyTorch
- timm
- HTML/CSS

## Diseases Detected
- Bacterial Blight
- Brown Spot
- Leaf Smut
