# 🌾 Rice Leaf Disease Detection using Vision Transformer (ViT)

A deep learning web application that detects rice leaf diseases from uploaded images using a Vision Transformer (ViT) model. The application is built with Flask and provides instant disease predictions through a simple web interface.

---

## 🚀 Features

- Upload rice leaf images
- Detect multiple rice leaf diseases
- Vision Transformer (ViT) based classification
- User-friendly web interface
- Real-time prediction results
- Flask-powered backend

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/santhoshworkspace26/rice-leaf-detection.git
cd rice-leaf-detection
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
